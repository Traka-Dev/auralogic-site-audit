## Spanish developer community

Creamos Aura Logic Site Audit, una CLI open source para revisar sitemaps XML, canonical, hreflang en HTML y enlaces internos rotos. Incluye una demo local con errores intencionales, reportes JSON y prompts para convertir hallazgos en cambios verificables. Requiere Node 22.22.1+; recomendamos Node 24. Aún no está publicado en npm. Buscamos ejemplos reproducibles de errores y feedback sobre los diagnósticos.

Repositorio: https://github.com/Traka-Dev/auralogic-site-audit
Guía: https://auralogic.dev/es/insights/auditar-hreflang-canonical-astro/

## English developer community

We built Aura Logic Site Audit: an MIT-licensed CLI for XML sitemaps, HTML canonical/hreflang and broken internal links. It includes a local fixture, JSON reports and an evidence-based AI repair workflow. It runs locally on Node 22.22.1+ (24 recommended); no hosted scanner or npm release yet. Feedback and reproducible bug reports are welcome, especially for bilingual static sites.

https://github.com/Traka-Dev/auralogic-site-audit
https://auralogic.dev/insights/audit-hreflang-canonical-astro/

## Short professional post

Un canonical incorrecto o un hreflang sin retorno puede pasar desapercibido en una web bilingüe. En Aura Logic publicamos una herramienta MIT y una guía práctica para detectar estos casos, corregir su fuente y comprobar el resultado. La demo tiene fallos intencionales para aprender sin usar datos de clientes.

https://auralogic.dev/es/herramientas/auditor-seo/
